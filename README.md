## 🛠️ Tecnologías y Técnicas Utilizadas

En el desarrollo de este proyecto implementé las siguientes tecnologías y metodologías de desarrollo web:

- HTML5 Semántico: Estructuración limpia del contenido para mejorar la accesibilidad (a11y) y el SEO básico.
- CSS3 Moderno:
  - Variables CSS (`:root`) para mantener la consistencia de colores, tipografías y temas.
  - Maquetación flexible utilizando Flexbox.
  - Diseño totalmente adaptable Responsive Design mediante Media Queries ajustadas para móviles, tablets y escritorios.
  - Metodología de nombrado BEM (Block Element Modifier) para mantener un código legible, modular y mantenible.
- Control de Versiones: Git y GitHub para la gestión de commits y publicación continua.
